Examine and decompile .NET programs.

**Website**: [https://github.com/icsharpcode/ILSpy](https://github.com/icsharpcode/ILSpy)\
**Author**: AlphaSierraPapa and [https://github.com/icsharpcode/ILSpy/graphs/contributors](https://github.com/icsharpcode/ILSpy/graphs/contributors)\
**License**: MIT License: [https://github.com/icsharpcode/ILSpy/blob/master/doc/ILSpyAboutPage.txt](https://github.com/icsharpcode/ILSpy/blob/master/doc/ILSpyAboutPage.txt)\
**Available on**: Intel/AMD (amd64) and ARM (arm64)\
**Notes**: This is the command-line version of ILSpy, which you can run using the `ilspycmd` command.\

## CILantro

Deobfuscate and unpack .NET programs protected with .NET Reactor, ConfuserEx, Babel .NET, or Dotfuscator, without running them.

**Website**: [https://github.com/jgajek/cilantro](https://github.com/jgajek/cilantro)\
**Author**: Jacob Gajek: [https://x.com/jgajek](https://x.com/jgajek)\
**License**: MIT License: [https://github.com/jgajek/cilantro/blob/main/LICENSE](https://github.com/jgajek/cilantro/blob/main/LICENSE)\
**Available on**: Intel/AMD (amd64) and ARM (arm64)\
**Notes**: cilantro\
**State File**: [remnux.tools.cilantro](https://github.com/REMnux/salt-states/blob/master/remnux/tools/cilantro.sls)
